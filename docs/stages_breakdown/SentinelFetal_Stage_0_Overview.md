## 🔒 Invariants גלובליים

חוקים אלה **חייבים להישמר בכל השלבים**:

| מזהה | כלל | הסבר |
|------|-----|------|
| **G1** | אמת אחת לקונפיג | כל הפרמטרים מגיעים מ־runtime config יחיד |
| **G2** | fs קנוני = 4Hz | זהו תדר הבסיס. מקור אחר → resample או FAIL |
| **G3** | Windowing קנוני | חלון = 20 דקות, קפיצה = 5 דקות (4800/1200 דגימות) |
| **G4** | חלון < 20m = FAIL | חלון קצר מדי נפסל ולא נכנס לעיבוד |
| **G5** | Padding Shield | כל padding מסומן invalid ולא נכנס לחישובים |
| **G6** | Truth לפני תיקון | מסכות נקבעות על RAW, לפני imputation |
| **G7** | Strict Mode | במצב strict: כל סטייה → FAIL עם סיבה ברורה |
