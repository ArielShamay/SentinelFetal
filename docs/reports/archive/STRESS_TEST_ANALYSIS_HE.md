## ⚠️ ניתוח צוואר הבקבוק

### העיבוד הגרפי (Plotly) הוא הבעיה המרכזית

**הממצא המרכזי:** רכיב ה-Plotly צורך **94.8%** מזמן העיבוד הכולל.

#### מה קורה בכל מחזור?
1. יצירת אובייקט `Figure` חדש לכל מטופלת
2. הוספת trace עם 60 נקודות נתונים
3. עיצוב והגדרות layout
4. **המרה ל-JSON** (הצעד הכבד ביותר - `fig.to_json()`)

#### למה זה בעייתי?
- כל מטופלת נוספת מכפילה את זמן העיבוד הגרפי
- Streamlit דורש JSON serialization לכל figure
- אין caching של אובייקטים גרפיים
