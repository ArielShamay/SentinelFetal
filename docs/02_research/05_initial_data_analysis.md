# דוח ניתוח נתונים: CTU-CHB Intrapartum Cardiotocography Database

## ממצאים עיקריים

### 1. פורמט הנתונים
הנתונים מאורגנים בפורמט **WFDB (WaveForm Database)**, שהוא הסטנדרט המקובל של [PhysioNet](https://physionet.org) לשמירת אותות פיזיולוגיים.
זהו **אינו** קובץ CSV או טבלה יחידה, וגם לא JSON. מדובר באוסף של קבצים בינאריים וטקסטואליים המקושרים זה לזה עבור כל רשומה רפואית.

עבור כל מטופלת (רשומה) קיימים צמד קבצים:
*   **קבצי `*.dat` (בינארי):** מכילים את הדאטה הגולמי של האותות (Time-series data). הנתונים שמורים כמספרים שלמים (16-bit integers).
*   **קבצי `*.hea` (טקסט):** קבצי כותרת (Header) המכילים מטא-דאטה קריטי: הגדרת האותות (תדר דגימה, יחידות מידה) ונתונים קליניים (Clinical Attributes).

### 2. הרכב האותות (Signals)
כל רשומה מכילה שני ערוצי דגימה עיקריים, הנדגמים בתדר של **4Hz** (ארבע דגימות בשנייה):
1.  **FHR (Fetal Heart Rate):** דופק העובר. יחידות: פעימות לדקה (`bpm`).
2.  **UC (Uterine Contractions):** צירים (פעילות רחמית). יחידות: לא מוגדרות (`nd` - non-dimensional), בדרך כלל סקאלה יחסית (0-100).

### 3. מטא-דאטה קליני
קבצי הכותרת (`.hea`) עשירים מאוד במידע קליני המופיע כהערות (`#`). המשתנים הקיימים כוללים:
*   **מדדי תוצאה (Outcome Measures):** pH חבל הטבור (מדד קריטי), BDecf, pCO2, BE, ציוני אפגר (Apgar) בדקה 1 ו-5.
*   **נתוני הילוד:** משקל, מין, שבוע הריון.
*   **נתוני האם:** גיל, מספר הריונות (Gravidity), מספר לידות (Parity).
*   **גורמי סיכון:** סוכרת, יתר לחץ דם, רעלת הריון (Preeclampsia), ועוד.
*   **אופן הלידה:** סוג המצג (Presentation), אופן הלידה (וגינלי/קיסרי - מופיע לעיתים בקודים).

### 4. היקף הדאטה
*   **מספר רשומות כולל:** 552 רשומות ייחודיות (מזהים 1001 עד 2046, עם רווחים אפשריים או סדר רציף בחלק מהטווחים).
*   **משך הנתונים:** הדוגמה שנבדקה (רשומה 1001) מכילה 19,200 דגימות, השוות ל-80 דקות של ניטור רציף.

## מסקנות והמלצות

1.  **קריאת הנתונים:**
    *   לא ניתן לפתוח את הקבצים ישירות באקסל.
    *   מומלץ להשתמש בספריית Python ייעודית בשם **`wfdb`** (חבילת ה-WFDB של PhysioNet). היא יודעת לקרוא את קבצי ה-`.hea` וה-`.dat` ולייצר מהם אובייקטים נוחים לעבודה (NumPy Arrays, Metadata Dictionaries).
    *   לחלופין, ניתן לכתוב סקריפט פרסר (Parser) פשוט אם רוצים להימנע תלויות, אך השימוש ב-`wfdb` מומלץ לאמינות.

2.  **שימושים אפשריים:**
    *   הדאטה מתאים מאוד למשימות **Machine Learning** לחיזוי מצוקה עוברית (למשל, חיזוי pH נמוך בלידה) על בסיס הניטור הרציף וגורמי הסיכון.
    *   המידע הקליני המפורט מאפשר פילוח אוכלוסיות (למשל, השוואת דפוסי דופק בנשים עם סוכרת לעומת נשים בריאות).

3.  **פעולה מיידית מומלצת:**
    *   התקנת ספריית `wfdb`: (`pip install wfdb`).
    *   כתיבת סקריפט Python ראשוני לטעינת רשומה אחת והצגת הגרף (FHR ו-UC) כדי "להרגיש" את הדאטה.
    *   יצירת טבלה אחת מרוכזת (CSV) מתוך כל קבצי ה-header עבור המטא-דאטה הקליני, כדי שיהיה קל לחקור את התפלגות המשתנים (כמה לידות קיסריות, התפלגות משקלים, וכו').
