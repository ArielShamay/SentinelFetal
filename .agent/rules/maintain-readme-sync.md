# שמירה על סנכרון (Keep docs/README_HE.md Synced)

חוק זה נועד להבטיח שקובץ **`docs/README_HE.md`** יישאר עדכני בכל זמן נתון.
**שים לב:** חוק זה חל **אך ורק** על הקובץ `docs/README_HE.md`. אין להחיל אותו על `README.md` הראשי או כל קובץ תיעוד אחר.

## מתי להפעיל?
בכל פעם שמתבצע אחד מהשינויים הבאים:
1.  **שינוי במבנה התיקיות:** הוספה, מחיקה או שינוי שם של תיקיות מהותיות.
2.  **שינוי בתיקיית `docs/`:** הוספה או פיצול של מסמכי תיעוד.
3.  **שינוי בסקריפטים:** הוספת סקריפט חדש שדורש תיעוד או שינוי אופן הרצה.
4.  **שינוי בתהליכי התקנה:** שינוי ב-`requirements.txt` או הוראות הרצה.

## פעולות נדרשות
1.  בדוק אם ה-`docs/README_HE.md` מכיל מידע ישן או חסר בעקבות השינוי.
2.  אם כן, עדכן את הסעיפים הרלוונטיים בקובץ זה בלבד (למשל: עץ תיקיות, רשימת סקריפטים, הוראות הפעלה) מיידית כחלק מאותה משימה.
